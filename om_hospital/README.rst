This module provides a comprehensive solution for managing hospital operations, patients, clinicians, clinics, and appointments.

Features
========
* Patient and clinician management
* Appointment scheduling and tracking
* Ward and bed transfers via dedicated wizards
* Hospital admissions, tracking, and discharge summaries
* Custom QWeb PDF reports (Prescription Slips, Appointment Slips, and Discharge Summaries)
* Seamless integration with Odoo Sales and configurations
